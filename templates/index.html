PiSpider

This app has two parts. SoloHost is the panel. Windows Worker does the Node work on this PC.

TWO PARTS — TERMS 
What this is
PiSpider is one product in two parts on YOUR computer:
1) SoloHost panel (this page) — status, buttons, terms.
2) Windows Worker — PowerShell that reads Docker / Pi Node on Windows.

The panel does not repair the Node by itself. The Worker does.

What is ON by default
SoloHost sandbox only: this page, the app folder, localhost port 18770.
The Worker runs only after you start it on Windows.

What you grant if you Confirm
• The Worker may read Node / Docker / disk status on this Windows PC.
• The panel may send only whitelist commands: scan, repair, status, patrol.
• No random PowerShell from the browser.

What we do not claim
• No access to your Pi wallet or keys.
• No Docker socket unless you enable that separately.
• Publisher does not operate your PC.

Your responsibility
You start and stop the Windows Worker. You can delete the WindowsWorker folder anytime.

After Confirm
Click START WINDOWS WORKER (or run Start-Worker.cmd in this app folder).
Then use SCAN / STATUS / REPAIR on this page.

Confirm only if you accept these terms in full.
