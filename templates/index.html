PiSpider Hybrid

SoloHost is the dashboard. Windows Worker does the Pi Node work on the Windows PC.

Before you start

PiSpider has 2 parts:

1
SoloHost
The web dashboard: status, commands and results.
2
Windows Worker
A PowerShell worker running on the Windows PC that has Pi Node / Docker.
Simple terms
  • The Worker can read Windows, Docker and Pi Node status.
  • The dashboard sends only predefined commands such as Scan, Status, Patrol and Repair.
  • No Pi wallet, passphrase or private key is requested.
  • SoloHost cannot directly start a Windows program from inside its container. You start the Worker on Windows.

Step 2 — Start the Windows Worker

Use one method below. The first method is easiest.

Method A — double-click

Open the PiSpider SoloHost app folder on Windows and double-click:

Start-Worker.cmd

Method B — PowerShell

Open PowerShell in the PiSpider app folder:

powershell -NoProfile -ExecutionPolicy Bypass -File ".\WindowsWorker\LiveWorker.ps1"

Method C — CMD

Open CMD in the PiSpider app folder:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\WindowsWorker\LiveWorker.ps1"

Method D — download the Worker package

If the Worker files are missing on Windows, download the package, extract it into the SoloHost app folder, then run:

.\WindowsWorker\Activate_Worker.bat

Important: Do not run two Worker windows at the same time. Keep one Worker window open while testing.
