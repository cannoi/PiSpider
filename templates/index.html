PiSpider Hybrid

SoloHost control + Windows Worker execution. The dashboard mirrors the Worker operating view.

Before you start

PiSpider has 2 parts:

1
SoloHost
Dashboard, commands, live status and results.
2
Windows Worker
PowerShell worker that performs Pi Node / Docker work on Windows.

Step 2 — Start Windows Worker

Use one method. The launcher automatically finds WindowsWorker\LiveWorker.ps1 under %APPDATA%\Pi Network\pi-apps\.

PowerShell

$r=Join-Path $env:APPDATA 'Pi Network\pi-apps'; $w=Get-ChildItem $r -Filter LiveWorker.ps1 -Recurse -File | Where-Object { $_.FullName -match '\\WindowsWorker\\LiveWorker\.ps1$' } | Select-Object -First 1; if($w){powershell.exe -NoProfile -ExecutionPolicy Bypass -File $w.FullName}else{Write-Host 'WindowsWorker\\LiveWorker.ps1 not found' -ForegroundColor Red}

CMD

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "$r=Join-Path $env:APPDATA 'Pi Network\pi-apps'; $w=Get-ChildItem $r -Filter LiveWorker.ps1 -Recurse -File | Where-Object { $_.FullName -match '\\WindowsWorker\\LiveWorker\.ps1$' } | Select-Object -First 1; if($w){& powershell.exe -NoProfile -ExecutionPolicy Bypass -File $w.FullName}else{Write-Host 'Worker not found'}"

Download / extract

Extract the ZIP contents into:

%APPDATA%\Pi Network\pi-apps\<PiSpider app folder>\WindowsWorker\

Required file:

%APPDATA%\Pi Network\pi-apps\<PiSpider app folder>\WindowsWorker\LiveWorker.ps1

Then double-click Start-Worker.cmd. The launcher requests Administrator and hides the command window.
